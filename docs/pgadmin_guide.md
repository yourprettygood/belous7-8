# Руководство по работе с pgAdmin 4 и базой данных `user_auth_db`

Данный документ содержит пошаговую инструкцию по администрированию и проверке базы данных практической работы №8-9 через среду **pgAdmin 4**.

---

## 1. Запуск pgAdmin 4
1. Откройте меню **Пуск** и найдите **pgAdmin 4** (или запустите исполняемый файл `C:\pgAdmin 4\runtime\pgAdmin4.exe`).
2. При первом запуске введите мастер-пароль для хранилища ключей pgAdmin (если запрашивается).

---

## 2. Подключение к серверу PostgreSQL
1. В левой панели **Browser** разверните узел **Servers**.
2. Если локальный сервер еще не зарегистрирован:
   - Нажмите правой кнопкой мыши по **Servers** -> **Register** -> **Server...**.
   - На вкладке **General**:
     - **Name**: `PostgreSQL 18 (Local)`
   - На вкладке **Connection**:
     - **Host name/address**: `127.0.0.1` или `localhost`
     - **Port**: `5432`
     - **Maintenance database**: `postgres` (или `user_auth_db`)
     - **Username**: `postgres`
     - **Password**: `postgres`
     - Установите галочку **Save password?**
   - Нажмите кнопку **Save**.

---

## 3. Развертывание схемы базы данных
Если база `user_auth_db` еще не создана:
1. Нажмите правой кнопкой мыши по **Databases** -> **Create** -> **Database...**.
2. Введите имя базы: `user_auth_db` и нажмите **Save**.
3. Выберите базу `user_auth_db`, нажмите в верхнем меню **Tools** -> **Query Tool** (или значок блокнота с молнией).
4. Откройте файл `sql/schema.sql` из репозитория (`Ctrl + O`) или скопируйте его содержимое в окно редактора запросов.
5. Нажмите клавишу **F5** (или кнопку **Execute query ▶**).

---

## 4. Просмотр структуры таблиц
В левой панели разверните дерево:
```text
Servers
 └── PostgreSQL 18 (Local)
      └── Databases
           └── user_auth_db
                └── Schemas
                     └── public
                          └── Tables
                               ├── СекретныйВопрос
                               └── Пользователь
```

Для просмотра структуры колонок и ключей таблицы нажмите правой кнопкой мыши на таблицу -> **Properties...**:
- **Колонки таблицы `СекретныйВопрос`**:
  - `КодСекретногоВопроса` (integer, Primary Key, Identity)
  - `СекретныйВопрос1` (character varying(255))
- **Колонки таблицы `Пользователь`**:
  - `КодПользователя` (integer, Primary Key, Identity)
  - `Фамилия`, `Имя`, `ЭлектроннаяПочта`, `Пароль`, `КодовоеСлово`, `ОтветНаСекретныйВопрос`
  - `КодСекретногоВопроса` (integer, Foreign Key ссылается на `СекретныйВопрос`)

---

## 5. Просмотр и редактирование данных
1. Чтобы просмотреть все строки таблицы:
   - Нажмите правой кнопкой мыши по таблице `Пользователь` -> **View/Edit Data** -> **All Rows**.
2. Либо выполните в **Query Tool** SQL-запрос:
```sql
SELECT 
    u."КодПользователя",
    u."Фамилия",
    u."Имя",
    u."ЭлектроннаяПочта",
    q."СекретныйВопрос1" AS "СекретныйВопрос",
    u."ОтветНаСекретныйВопрос",
    u."КодовоеСлово"
FROM "Пользователь" u
JOIN "СекретныйВопрос" q ON u."КодСекретногоВопроса" = q."КодСекретногоВопроса"
ORDER BY u."КодПользователя";
```

При регистрации новых пользователей через WPF-приложение `BelousAuthApp` данные будут моментально отображаться при повторном выполнении запроса в pgAdmin 4!
